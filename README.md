## Virtual Reality Classroom Simulation

The Virtual Reality Classroom Simulation is an interactive learning environment designed to train users on recognizing and responding appropriately to bystander-effect situations related to sexual misconduct. The simulation focuses on user immersion, decision-making, and real-world application.

Project Overview:
This project creates a virtual classroom environment where users encounter scenarios that challenge their awareness, moral reasoning, and intervention strategies. Through interactive prompts, character dialogue, and branching paths, the simulation encourages users to practice identifying harmful situations and taking appropriate action.

Purpose and Impact:
- Virtual reality training simulation for bystander intervention.
- Bystander intervention is taking action to prevent harm in a potentially harmful situation.
- Teach individuals the proper actions to take when witnessing sexual misconduct, emphasizing the importance of bystander awareness and effective intervention. 
- Classroom simulation scene; users learn and practice the 5Ds of bystander intervention: **Direct, Distract, Delegate, Delay, and Document.**
